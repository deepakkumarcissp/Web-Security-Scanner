Configuration / Integrations

Scanner Tool Setup

Discover installed Kali security tools, their capabilities, versions and integration status.
Dynamic tool inventory: The registry maps tools to capabilities and risk levels. Missing tools can be installed only from the fixed package allow-list after local confirmation. Inventory-only tools are not automatically run by scans; active or high-volume tools require dedicated integration and scope controls. Do not expose this dashboard to untrusted networks.
